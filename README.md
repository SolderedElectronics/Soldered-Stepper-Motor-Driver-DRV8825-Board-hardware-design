# Stepper Motor Driver DRV8825 Board Hardware Design

Open-source hardware design files for Stepper Motor Driver DRV8825 Board ([solde.red/333000](https://solde.red/333000)).

- `CAD/` — KiCad source, by version.
- `OUTPUTS/` — production files (gerbers, BOM, iBOM, 3D, schematics, pinout), by version.

Managed by Soldered Spark (PIM). All Soldered OSH is under the TAPR Open Hardware License.
